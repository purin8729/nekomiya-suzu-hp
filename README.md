# 猫宮 鈴 HP

猫宮 鈴（ねこみや すず）の紹介用静的サイトです。

## GitHub Pagesで公開する場合

1. GitHubで新しいリポジトリを作成します。
2. このフォルダの内容をリポジトリへ追加してpushします。
3. GitHubの `Settings` → `Pages` を開きます。
4. `Deploy from a branch` を選び、`main` ブランチの `/root` を指定します。
5. 数分後、表示されたURLでサイトを確認できます。

このサイトは `index.html` と `styles.css` だけで動くため、GitHub Pagesで公開できます。
